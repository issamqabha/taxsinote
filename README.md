# 🚖 TaxsiNote

**TaxsiNote** is a lightweight and practical mobile application designed to help taxi drivers track their daily trips, earnings, and expenses بسهولة and without complexity.

The app focuses on simplicity and speed, making it easy for drivers to manage their financial activity during the day.

---

## 📌 Overview

Taxi drivers often struggle with tracking their daily income and expenses in an organized way.  
**TaxsiNote** provides a simple solution that allows users to:

- Record trips quickly  
- Calculate earnings automatically  
- Monitor expenses  
- Understand their daily profit  

---

## ✨ Features

- 🚕 Add and manage taxi trips  
- 💰 Automatic earnings calculation  
- 📊 Expense tracking  
- 🧮 Net profit calculation  
- 📝 Simple and user-friendly interface  
- ⚡ Fast and responsive performance

## ⚙️ Installation

1. Clone the repository:

git clone https://github.com/issamqabha/taxsinote.git

2. Navigate to the project directory:

cd taxsinote

3. Install dependencies:

flutter pub get

4. Run the app:

flutter run
